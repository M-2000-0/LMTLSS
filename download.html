Installation Instructions

For iOS (TestFlight)

  1. Tap the "Download for iOS" button above
  2. Accept the TestFlight invitation if prompted
  3. Install the app from TestFlight
  4. Trust the developer if asked in Settings > General > VPN & Device Management

For Android (APK)

  1. Tap the "Download for Android" button above
  2. Allow downloads from your browser if prompted
  3. Open the downloaded APK file
  4. Allow installation from unknown sources if prompted
  5. Install and open LMTLSS

Note: Update the download links above with your actual TestFlight and APK URLs once deployed.
